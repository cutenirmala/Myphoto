# MyPhotos - Personal Photo & Video Gallery

A modern, full-featured photo and video management application built with Next.js, Supabase, and Tailwind CSS.

## Features

- 🔐 Authentication (Sign up, Login, Forgot Password)
- 📸 Photo & Video Upload (Drag & Drop)
- 🖼️ Beautiful Gallery with Masonry Layout
- 📁 Album Management
- ⭐ Favorites
- 🗑️ Trash with Restore
- 🔍 Powerful Search
- 👤 User Profile
- 📊 Storage Management
- 🔗 Share Photos & Albums
- 🎬 Video Player
- 🌓 Dark/Light Mode
- 📱 Fully Responsive
- 🔒 Secure & Private

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Database:** Supabase (PostgreSQL)
- **Storage:** Supabase Storage
- **Authentication:** Supabase Auth
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **Icons:** React Icons
